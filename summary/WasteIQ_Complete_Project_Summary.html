🌍 2. Ye Project Kyun Banaya? (Vasai-Virar Ka Kachra Sankat — Real Life Story)

  • Hamara Solution: Agar log apne ghar par hi kachra alag-alag kar lein (Wet, Dry, Hazardous), toh 80% kachra landfill jane se bach sakta hai. WasteIQ isi kaam ko bilkul aasan banata hai.

☁️ 7. Dual-Storage Resilience Architecture (MongoDB + Clerk Sync)

Teacher poochte hain: "Data kahan store ho raha hai?"

Humne Dual-Storage Architecture lagaya hai:

1. Clerk User Cloud Metadata (`publicMetadata`): User ke total points, scans count aur current rank Clerk ke cloud me store hote hain. Isse jab user login karta hai, toh profile sub-10 millisecond me load ho jati hai bina database par load dale.

2. MongoDB Atlas Database: Har individual scan ka full historical record (item name, category, bin color, date/time) MongoDB me save hota hai. Isse Super Admin dashboard par search, filters aur CSV export kaam karta hai.

Zero Downtime Benefit: Agar kisi din MongoDB ka network slow bhi ho, tab bhi user ka profile aur points crash nahi hote! Wo Clerk se instantly chalte rehte hain.

🎮 8. Gamification & Science Math: Points Aur CO₂ Formula

Teacher agar pooche: "CO₂ ka number tumne kahan se nikala?"

Aap batayenge: "Sir, Central Pollution Control Board (CPCB) aur EPA standard carbon offset formula use kiya hai:"

  • PET Plastic Bottle: Landfill me 1 kg plastic dump hone se $1.65\text{ kg } CO_2$ banta hai. Ek 50g bottle recycle karne se: $0.05\text{ kg} \times 1.65 = \mathbf{0.0825\text{ kg CO}_2\text{ saved}}$!
  • Aluminum Beverage Can: Bauxite mining aur smelting bohot power-intensive hoti hai ($9.10\text{ kg } CO_2/kg$). Ek can ($15g$) se: $0.015\text{ kg} \times 9.1 = \mathbf{0.136\text{ kg CO}_2\text{ saved}}$!
  • Cardboard Box: Paper production factor $0.95\text{ kg } CO_2/kg$. Ek 150g box se: $\mathbf{0.142\text{ kg CO}_2\text{ saved}}$!
